# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Website for Panino Focacceria, a market stall selling homemade Tuscan-style focaccia sandwiches.

## Commands

```bash
pnpm dev      # Start dev server on port 3000
pnpm build    # Build for production to ./dist/
pnpm preview  # Preview production build
```

## Stack

- Astro (static site)
- Tailwind CSS
- League Spartan font
- pnpm for package management

## About the Business

- One-man operation run by a chef with 30+ years of high-level international kitchen experience
- Found at Oxfordshire markets: Bicester (Fri), Kidlington (Sat), Thame (Tue)
- Everything is homemade — every bread, sauce, and side made from scratch
- Sandwiches are built to order at the stall
- The focaccia is simple: flour, water, yeast, salt, time
- Fillings use bought-in meat and veg, but everything is assembled and prepared fresh
- Gets a lot of regulars
- Six sandwiches with Italian mob-style names: "Big Paulie" Trentino, "Little Vinnie" Mancuso, "The Don", "The Big Cheese" Caprese, "Pretty Boy" Rossi (veggie), "Fat Tony" Falcone
- All sandwiches £7.50, plus a daily special and soup of the day
- Soups rotate: beef & barley (most popular, hearty), minestrone, tomato. All topped with parmesan and pesto

## Copy / Tone

- Avoid AI-sounding copy — no "one bite and you'll be planning the next" type lines
- Let the food and experience speak for itself, don't be cocky or salesy
- Keep it plain, honest, factual. State what it is, let people draw conclusions
- The sandwich names have personality on their own — lean into them
